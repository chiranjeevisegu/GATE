# GATE DA Handbook

I’m building this handbook for my own preparation for the GATE Data Science and Artificial Intelligence (DA) paper. I wanted one place to learn a topic, work through an example, solve a question, and revisit my mistakes later. I’m sharing it in case it helps with your preparation too.

**[Open the GATE DA Handbook](https://chiranjeevisegu.github.io/GATE/)** 

The hosted site is currently private. If the link asks for access, reach out to me.

## What’s inside

| Handbook | Topics |
| --- | --- |
| AI & Machine Learning | Regression, classification, clustering, PCA, search, logic, and probabilistic inference |
| Data Structures & Algorithms | Python, data structures, sorting, graphs, SQL, and data warehousing |
| Maths & Problems | Probability, statistics, linear algebra, calculus, and General Aptitude |

- **88 searchable lessons** with definitions, worked examples, visual walkthroughs, and links to further reading.
- **136 graded practice questions** across foundation, exam-level, and mixed practice modes.
- **195 previous-year questions from 2024–2026** with links to the exact pages in the official papers, 52 on-site walkthroughs, and external solution links for the remaining questions.
- **Three timed mocks** with exam-style scoring, saved answers, mark-for-review, and chapter-level results.
- **Revision tools** including a 16-question diagnostic, a weekly study plan, a mistake notebook, formula sheets, and flashcards.

## Start studying

If you’re working out where to begin, take the [diagnostic test](https://chiranjeevisegu.github.io/GATE/#exam/diagnostic) and use the results to build a study plan. If you already know your weak topic, search for it, read the lesson, and try the linked practice and past questions.

For offline study, extract the ZIP and open **index.html** in your browser. Lessons and original practice work offline. Official paper PDFs and external explanations require internet access. Your progress is stored in the browser you use.

## Project files

The site uses HTML, CSS, and vanilla JavaScript. Open **dist/index.html** in a browser to run it locally. After editing the site, run **python build-download.py** to rebuild the offline ZIP.

The handbook follows the official DA syllabus and uses official question papers and answer keys for scoring. [GATE syllabus](https://gate2027.iitm.ac.in/exam_papers_and_syllabus) · [Official past papers and keys](https://gate2026.iitg.ac.in/download.html)
